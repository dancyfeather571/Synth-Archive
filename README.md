# Synth-Archive

**Vintage character. Reimagined sound.**

Synth-Archive is a free collection of experimental synthesizer instruments created through sampling, layering, sound design, and resynthesis.

The collection explores atmospheric pads, expressive keys, haunting digital textures, unusual leads, powerful basses, and sounds inspired by classic analog and digital synthesizers.

> **Status:** The sampled expansion is **not yet available for download**. See [Availability](#availability).

## About

I created Synth-Archive because I love synthesizers and sound design.

I wish I owned actual synthesizer hardware. With real hardware, I could experiment even further and create sounds directly from the instruments themselves. For now, this project is my way of exploring those possibilities with the resources I have.

My goal is to make unique sounds, learn more about sound design, and share my work with others.

Synth-Archive is intended to be free for everyone once the sample redistribution permissions are confirmed.

## Features

- 60 synthesizer presets
- Vintage analog and digital character
- Atmospheric pads and evolving textures
- Keys, bells, leads, basses, and experimental instruments
- Custom multisampled instruments
- Sustain loops where appropriate
- Velocity-sensitive playback
- Full MIDI keyboard mappings
- Custom Synth-Archive artwork
- Designed for the Fraction plugin

## Availability

The project documentation and authorized source code are freely available in this repository.

The complete sampled expansion download is not yet public because redistribution permissions for the included recordings have not been confirmed.

Once permission is obtained, the expansion will be offered for free through this repository's GitHub Releases page.
